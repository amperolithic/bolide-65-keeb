# CAD Notes

* To find the `.step` file for each individual component, look in the `production` folder.
    * Most 3D models came from KiCad's default libraries. Anythig else came from [GrabCAD](https://grabcad.com/library/cherry-mx-stabilizer-mx-1) or the [scottokeebs](https://github.com/joe-scotto/scottokeebs/tree/main/Extras/ScottoKicad/3dmodels) Github. Keycaps were from [Kael Ruland](https://github.com/anhthang/dsa-keycap).

* The `.json` file was used to generate the top plate using the [ai03 Plate Generator](https://kbplate.ai03.com/).

* The source design can be found [here](https://cad.onshape.com/documents/e20ea32dfc7030467aec0ff3/w/b7b45069ea496daed0bdf8db/e/1ffd2733c11c98bf9e533695?renderMode=0&uiState=6af77d7c11999bcd9a8952bf).
